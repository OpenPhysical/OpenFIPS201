# GSA ICAM Card Builder Test Material

This directory contains the complete `46_Golden_FIPS_201-2_PIV` card folder from
the U.S. General Services Administration's `gsa-icam-card-builder` repository.

- Source: `https://github.com/GSA/gsa-icam-card-builder`
- Source commit: `6d5a872547b96c48dff7fc7c14ae1d205438ae38`
- Retrieved: 2026-08-11
- License: CC0 / U.S. public domain, reproduced in `LICENSE.md` and `LICENSE.txt`

Card 46 is an official FIPS 201-2 / SP 800-73-4 interoperability image. It is
kept byte-for-byte for GSA compatibility testing. Its legacy CHUID fields must
not be treated as a native SP 800-73-5 personalization profile.
